Put your real photos here, matching the paths referenced in frontend/src/content/*.js:

  hero/     -> homestay.js's `heroImage` (e.g. hero/hero.jpg)
  rooms/    -> rooms.js's per-room `images` arrays (e.g. rooms/double-bed-1.jpg)
  nearby/   -> nearbyPlaces.js's `image` field
  gallery/  -> optional extra gallery-only shots not tied to a specific room

Filenames: lowercase, hyphens, no spaces (e.g. double-bed-balcony.jpg, not "Double Bed (1).jpg").
Format: JPG or WebP, ~1600px on the longer edge, compressed under ~300KB (try squoosh.app).
This README and this whole images/ folder structure can be deleted once real photos are in place.
